# Instagram App – UI/UX Design Project

## Project Overview
The Instagram app is a social media platform that allows users to share photos, videos, reels, and stories. This project focuses on designing a simple, attractive, and user-friendly Instagram interface using Figma.

##  Objectives
- To create an easy-to-use social media interface.
- To help users share photos and videos.
- To improve user interaction through likes, comments, and messages.
- To design a visually appealing and responsive mobile layout.
- To provide smooth and simple navigation.

## Features
- Login & Sign Up: Create an account and log in.
- Home Feed: View posts from friends and followed accounts.
- Stories: Share photos and videos for 24 hours.
- Reels: Watch and share short videos.
- Explore: Discover new posts and accounts.
- Direct Messages: Chat with friends.
- User Profile: View posts, followers, and following.
- Notifications: Receive likes, comments, and follow updates.

## Design Highlights
- Clean and modern user interface.
- Instagram-inspired pink, purple, and orange gradient colours.
- Simple icons and easy navigation.
- Attractive image grids and story circles.
- Consistent typography and spacing.
- Reusable components created in Figma.
- Mobile-friendly design with a 440 × 956 px frame.
